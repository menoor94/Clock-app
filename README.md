🕐 Simple Clock
A live analog clock built with vanilla JavaScript, HTML, and CSS — updating in real time, right in the browser.

✨ Features

Displays the current time, updated every second
Hours, minutes, and seconds shown in real time
Clean, minimal design that works on any screen size


🛠️ Built With

HTML5 — structure and layout
CSS3 — clock styling, transforms for analog hands (if applicable)
Vanilla JavaScript — Date object, setInterval for real-time updates
